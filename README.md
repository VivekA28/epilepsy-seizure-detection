# Early Epilepsy Seizure Detection/Prediction

Final year project — CSE. Uses CHB-MIT Scalp EEG Database (PhysioNet)
for seizure detection/prediction, with SHAP/LIME interpretability layer
as the novel contribution.

## Attribution
Base implementation adapted from: https://github.com/mkfzdmr/Epileptic-EEG-Classfication-Using-Deep-Learning

## Dataset
CHB-MIT: https://physionet.org/content/chbmit/1.0.0/
Run `scripts/download_data.sh` to fetch locally (not included in repo — 42GB).
